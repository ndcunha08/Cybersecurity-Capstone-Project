# Healthcare Security Capstone Project

## Overview
This cybersecurity capstone project focuses on securing a healthcare organization called **MedLife Health Services Inc.**

The project combines:
- Risk assessment
- Security policy analysis
- Incident response
- Phishing breach simulation
- Security awareness training
- NIST Cybersecurity Framework implementation

The goal of this project was to identify security weaknesses within a healthcare environment and recommend improvements to strengthen the organization's overall security posture.

---

# Organization Overview

MedLife Health Services Inc. is a mid-sized healthcare organization consisting of:
- 3 clinics
- 1 centralized data center
- 255 employees

The organization handles:
- Patient medical records
- Billing information
- Clinical data
- Protected Health Information (PHI)

Because healthcare organizations manage highly sensitive data, strong cybersecurity controls are critical for protecting confidentiality, integrity, and availability.

---

# Problem Statement

Healthcare organizations are frequently targeted by cyberattacks due to the high value of patient information.

This project focuses on:
- Phishing attacks
- Credential theft
- Unauthorized access
- Weak security awareness
- Gaps in preventive security controls

The primary objective was to analyze how a phishing attack could impact the organization and determine what improvements are necessary to reduce organizational risk.

# Simulated Breach Scenario

## Attack Type
Phishing attack

## Attack Summary
An employee from the billing department received a phishing email disguised as an IT support message.

The email contained:
- A fake login link
- Credential harvesting page

The employee entered login credentials into the malicious website, allowing the attacker to gain unauthorized access to organizational systems.

---

# Breach Timeline

| Time | Activity |
|---|---|
| 08:30 | Phishing email received |
| 08:35 | Employee clicked malicious link |
| 09:10 | Attacker gained access |
| 09:30 | Suspicious activity detected |
| 10:00 | Incident containment initiated |

This demonstrates how quickly phishing attacks can escalate inside organizations.

---

# Root Cause Analysis

The breach occurred due to several weaknesses:

- No Multi-Factor Authentication (MFA)
- Weak phishing awareness training
- Poor email filtering
- Delayed preventive controls

The absence of MFA significantly increased organizational risk.

---

# Security Recommendations

The following improvements were recommended:

- Implement Multi-Factor Authentication (MFA)
- Deploy SIEM solutions
- Deploy Endpoint Detection & Response (EDR)
- Improve employee security training
- Strengthen email filtering systems
- Improve proactive monitoring

A layered security approach significantly improves organizational defense.

|---|---|

| Protect | Weak |

The organization demonstrated strong detection and response capabilities but required stronger preventive security controls.

---

# Lessons Learned

Key lessons learned from this project include:

- Human error remains one of the biggest cybersecurity risks
- Prevention is more effective than reaction
- Layered security is critical
- MFA should be mandatory
- Security awareness training must be continuous
